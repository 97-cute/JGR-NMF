# JGR-NMF
The three spatial transcriptomics datasets used in this study are publicly available from the 10x Genomics platform, as detailed below:
Breast Cancer-1 Dataset: https://www.10xgenomics.com/datasets/human-breast-cancer-block-a-section-1-1-standard-1-1-0
Breast Cancer-2 Dataset: https://www.10xgenomics.com/datasets/human-breast-cancer-ductal-carcinoma-in-situ-invasive-carcinoma-ffpe-1-standard-1-3-0
Mouse Kidney Dataset: https://www.10xgenomics.com/datasets/mouse-kidney-section-coronal-1-standard-1-1-0
